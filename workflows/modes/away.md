# CF Away

When invoked as `{{skill:away}}`, turn away mode on in the current conversation.
Acknowledge it in one line, then continue authorized work autonomously. For
ordinary judgment calls, take the recommended or safe default and report
assumptions. Do not begin the `{{skill:plan}}` interview while away.

Still ask before remote deletion, removing unclassified untracked files, or
deciding the disposition of a leaked credential. Never infer approval for a
destructive action without a safe default. Host permission and approval
requirements still apply.

Keep this choice in subsequent turns and compaction summaries until the user
changes it. Persist through the installed adapter when available. Only a successful runtime response proves it was written to disk.
Use `{{skill:active}}` to resume normal questions.
