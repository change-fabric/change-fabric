# CF yolo

When invoked as `{{skill:yolo}}`, select `yolo` for this session.
Acknowledge the choice in one line and continue the task.

Commit and push to the selected target branch. Do not create a new pull request. Merging an existing pull request is permitted within the user-authorized scope.

Ask the installed host adapter to persist the choice when available. If the
mode was loaded implicitly, use the explicit mode command provided in runtime
context with this selected mode and the exact session identity. Without
an adapter, keep it in conversation and compaction summaries. Check runtime
context on resume. A child session inherits its parent's mode until explicitly
changed; independent sessions must not change one another's mode.

Use `{{skill:cf}}` to choose another mode. This sets workflow intent;
it never changes host permissions or sandbox settings. Shell guards are advisory.
