# CF Active

When invoked as `{{skill:active}}`, turn away mode off in the current conversation.
Acknowledge it in one line. Resume asking questions when information or
approval is needed, using the available question tool or plain conversation.

Keep this choice in subsequent turns and compaction summaries until the user
changes it. Persist through the installed adapter when available. Only a successful runtime response proves it was written to disk.
Use `{{skill:away}}` to turn away mode on again.
