One file per repo

The root CHANGE.md says what to test and which branches and tags are protected.

CHANGE.md

---
change_config:
  project: example-app
  lanes:
    a11y:
      routes: [/, /pricing]
change_policy:
  protected_refs:
    - main
    - "tag:v*"
  promotion:
    main:
      require_change_pass: true
---
