# Option brief template

One file per option under `options/` (`a.md` to `e.md`). Keep each under one page.

```
# Option <letter>: <name>

## Concept
One paragraph: the idea, in plain words, and the feeling it should leave.

## Axes
- Concept: <the central metaphor or stance>
- Palette or material: <colors, textures, materials>
- Type or voice: <typefaces for visual work, tone of voice for copy>
- Composition: <layout, framing, density>
- Motion: <how it moves, or "none">
- Format: <medium and deliverables>

## What it is NOT
Two or three things this option deliberately refuses, naming the nearest default it avoids.

## Strongest case
Why this option wins, in two sentences.

## Weakest point
The honest risk: cost, audience fit, feasibility, or sameness.

## Moodboard prompt (only with --images)
The cf:image prompt for this option's board. Describe the look; never ask for UI screenshots or legible text.
```

Options must differ on at least three axes. If two options share concept, palette, and type, merge them and write a new one.
