# Line

Shows how one or more values change across an ordered sequence. Follow `grammar.md` for everything not stated here.

## When to use

- A trend over rounds, releases or weeks, with up to a few series to compare.

## When not to

- Unordered categories: use `bar.md`.
- Two numeric measures against each other: use `scatter.md`.

## Rules

- Keys are placed in the order they first appear, evenly spaced. Order them in the spec.
- The value axis is not forced to 0; it spans the data on a nice step, since a line is read for its shape.
- Each point is a mark circle that carries its value, so every value is checked and present in the data table.
